### 📦 Shipped

#### [Hardware Network Latency Analyzer](https://github.com/TommyGhaly/network_latency_analyzer) — Sub-Microsecond Network Profiling
> STM32 NUCLEO-F446RE · Embedded C · W5500 · Oracle Cloud

Hardware timestamper built for HFT infrastructure concepts. W5500 EXTI voltage interrupts trigger STM32 hardware timers the instant a UDP packet arrives — **11ns accuracy**, no OS scheduling jitter. Telemetry streams to an always-on Oracle Cloud backend; live latency and jitter stats render on an SSD1306 OLED. Measured round-trip latencies averaging **15µs**.

#### [Real-Time Stochastic Option Valuator](https://github.com/TommyGhaly/option-pricer) — Quantitative Finance Engine
> C++ · Python · Plotly Dash

High-performance options pricing and risk library implementing Black-Scholes, Binomial Trees, Monte Carlo, Heston stochastic volatility, SABR, Dupire local volatility, and Merton jump diffusion. Multi-threaded market data pipelines over 5+ years of history, real-time multi-model calibration, first- and second-order Greeks in an interactive Dash UI, and C++ optimizations delivering 10–100x speedups over naive implementations.
