### 🏗️ What I'm Building

#### [Taksis](https://github.com/TommyGhaly/Taksis) — Church Management, Modernized
> React Native · Expo · Firebase · MLKit

A full-scale production app serving **500+ users** across Coptic Orthodox communities. AI-powered deacon scheduling with complete admin allocation control, attendance tracking, push notifications, Pascha liturgical scheduling with bilingual Coptic/English assignments, license plate OCR traffic management, donations, and a Firestore superAdmin dashboard — all in one platform. Live on the App Store and Google Play.

#### [Hardware Network Latency Analyzer](https://github.com/TommyGhaly/network_latency_analyzer) — Sub-Microsecond Network Profiling
> STM32 · Embedded C · W5500 · Oracle Cloud

Hardware timestamper built for HFT infrastructure concepts. W5500 EXTI voltage interrupts trigger STM32 hardware timers the instant a UDP packet arrives — **11ns accuracy**, no OS jitter. Telemetry streams to an always-on Oracle Cloud backend; live latency and jitter stats render on an SSD1306 OLED. Measured round-trip latencies averaging **15µs**.

#### [Real-Time Stochastic Option Valuator](https://github.com/TommyGhaly) — Quantitative Finance Engine
> C++ · Python · Plotly Dash

High-performance options pricing engine implementing Black-Scholes, Heston stochastic volatility, SABR, Jump Diffusion, Monte Carlo, and Binomial Trees. Real-time market data pipelines, interactive Greeks visualization, and C++ optimizations delivering 10–100x speedups over naive implementations.
